# TreOps Landing Page

The official landing page and documentation for [TreOps](https://treops.ai) — a self-hosted operations platform for AI agents.

## Getting Started

### Development

```bash
pnpm install
pnpm dev
```

The landing page will be available at `http://localhost:3001`.

### Build

```bash
pnpm build
pnpm start
```

## Project Structure

- `/app` — Next.js pages and layout
  - `/docs` — Documentation pages
  - `page.tsx` — Landing page home
- `/components` — React components
  - `/docs` — Documentation components and navigation
- `/public` — Static assets
- `/lib` — Utility functions

## Technologies

- [Next.js](https://nextjs.org/) — React framework
- [TypeScript](https://www.typescriptlang.org/) — Type safety
- [Tailwind CSS](https://tailwindcss.com/) — Styling
- [Framer Motion](https://www.framer.com/motion/) — Animations
- [next-intl](https://next-intl-docs.vercel.app/) — Internationalization
